📥 Pruebas de @import en CSS

Cada una de estas cajas recibe sus estilos desde un archivo CSS externo diferente, usando las distintas modalidades de importación.

1. @import url()
Cargado usando la función url().
2. @import ""
Cargado usando simplemente un String.
3. Media Query
Reduce el ancho de tu navegador. Esta caja cambiará de color solo en pantallas pequeñas.
4. Supports(condición)
Esta caja tiene un diseño Grid inyectado SOLO si tu navegador soporta 'display: grid'.
AB
5. Layer(nombre)
Estilos encapsulados en una capa llamada "modulo-externo".
6. Layer() anónima
Estilos encapsulados en una capa sin nombre (ideal para resets).

🚀 Importar CSS vía JavaScript (CSS Module Scripts)

Esta caja no tiene estilos en nuestro CSS principal. Su diseño se inyecta dinámicamente convirtiendo el archivo en un objeto CSS StyleSheet mediante JS.

¡Si el script de JavaScript funciona correctamente, Los efectos de este contenedor serán visibles!
