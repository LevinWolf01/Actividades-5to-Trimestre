Laboratorio de `overflow` en CSS

Todas las cajas tienen un tamaño fijo de 200x120px. Observa cómo cambia el comportamiento:

1. overflow: visible (Por defecto)

Este texto es demasiado largo para una caja tan pequeña, por lo que se va a salir descaradamente sin importarle los bordes.

2. overflow: hidden

Este texto es demasiado largo para una caja tan pequeña, por lo que todo lo que no quepa en los límites será guillotinado y desaparecerá.

3. overflow: scroll

Aquí puedes leer todo el texto usando las barras de navegación vertical y horizontal que aparecen de forma obligatoria.

4. overflow: auto (El más recomendado)

El navegador es inteligente: si el texto se pasa, pone barra de scroll. Si el contenido cupiera justo, no pondría nada.

Rojo
Azul

2. Aplicando `float: left` a la Caja Roja

La caja roja flota a la izquierda. Mira lo que les pasa a la caja azul y al texto.

Rojo (Float)
Azul

Este es el texto del párrafo. Al estar la caja roja flotando, el texto detecta su presencia y empieza a "envolverla" fluyendo por el espacio libre que queda a su derecha.

3. Aplicando `clear: both` a la Caja Azul

La caja roja sigue flotando, pero la azul dice: "Yo no me pego a nada que flote".

Rojo (Float)
Azul (Clear)

Este es el texto del párrafo. Como la caja azul rompió el efecto del flotado, el flujo vuelve a la normalidad a partir de ella, y el texto se posiciona limpiamente abajo.
