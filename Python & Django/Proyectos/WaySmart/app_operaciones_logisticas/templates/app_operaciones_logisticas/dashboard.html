GUÍA DEL MODELO

Cómo se conectan los datos

Las etiquetas explican cuántos registros pueden participar en cada relación.

1:1
Operador ↔ PerfilOperador

Un operador tiene un único perfil y cada perfil pertenece a un operador.

1:n
Envío → Paradas

Un envío puede contener muchas paradas; cada parada pertenece a un envío.

n:m
Envíos ↔ Etiquetas

Un envío puede tener varias etiquetas y una etiqueta clasifica muchos envíos.
